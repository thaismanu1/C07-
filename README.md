# Projeto de Banco de Dados — Sistema de Vendas


Grupo:THAÍS EMANUELLE PRADO DE OLIVEIRA e MONIQUE SILVA PEREIRA AMORIM


## Sobre o projeto

Este projeto apresenta a modelagem de um banco de dados para um sistema de vendas. O modelo e organiza as informações de pessoas, clientes, funcionários, produtos, fornecedores, pedidos e notas fiscais.

O objetivo é permitir o cadastro e o acompanhamento de uma venda desde o cliente que realizou a compra até os produtos vendidos e a emissão da nota fiscal.

Organização do diagrama

No modelo, as tabelas foram separadas visualmente por assunto:

- **Pessoas:** `Pessoa`, `Cliente` e `Funcionario`;
- **Catálogo:** `Categoria` e `Produto`;
- **Fornecedores:** `Fornecedor` e `Fornecimento`;
- **Vendas:** `Pedido`, `ItemPedido` e `NotaFiscal`.
